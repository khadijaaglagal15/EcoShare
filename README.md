# EcoShare 🌱

EcoShare is a mobile application designed to give a second life to unused objects by allowing users to share, exchange, or make them available to other people.

## 📌 Project Overview

The main goal of EcoShare is to encourage reuse and reduce waste by creating a simple platform where users can discover available objects and give away items they no longer need.

The application provides a mobile interface for users and a REST API for managing the application's data and services.

## 🎯 Objectives

* Encourage the reuse of unused objects
* Reduce waste and unnecessary consumption
* Connect users who want to give away or receive objects
* Provide a simple and user-friendly mobile experience

## 🚀 Main Features

* User registration and authentication
* Browse available objects
* Search and explore objects
* View object details
* Add and manage objects
* Share unused objects with other users
* Manage user information

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/ecoshare.git
cd ecoshare
```

### 2. Backend Setup

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the Django server:

```bash
python manage.py runserver
```

### 3. Frontend Setup

Go to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the Expo application:

```bash
npx expo start
```

You can then run the application using an Android emulator, iOS simulator, or Expo Go.
